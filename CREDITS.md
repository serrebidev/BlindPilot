# Credits

BlindPilot is based on the original
**[Claude Code Reader](https://github.com/doubletaponair/claude-code-reader)**
by [doubletaponair](https://github.com/doubletaponair). The original project
established the application's accessibility-first desktop design, native
wxPython interaction model, navigable response rows, live activity
presentation, multi-session workflow, and Claude Code integration.

BlindPilot gratefully credits doubletaponair and every original contributor.
The upstream repository is the canonical source for its current contributor
history and original releases.

BlindPilot contributors added the new product identity, persistent backend
selection, OpenAI Codex app-server adapter, FreeBuff pseudo-terminal adapter,
provider-aware setup and controls, compatibility migration, stable accessible
stream batching, and expanded tests and documentation.

The provider-based Chat mode incorporates the architecture and implementation
from the AccessibleAI sibling project maintained by the same publisher. Its
account, profile, provider-protocol, secure-credential, attachment, streaming,
batch, cache, and accessible history work was adapted to live inside
BlindPilot's main window.

Claude and Claude Code are associated with Anthropic. Codex is associated with
OpenAI. FreeBuff is maintained by its respective project. These names identify
compatible third-party command-line backends; no endorsement is implied.
