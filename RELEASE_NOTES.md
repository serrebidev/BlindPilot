# BlindPilot 0.29.28

A Hermes update that worked can no longer be announced as a failure with a number no one can read. A friend who pressed Update on Hermes heard "Hermes update exited with code 4294901760" -- and stopped, believing the update had broken something. That number was never about Hermes.

- Why the number appeared: BlindPilot updates Hermes by running its official PowerShell installer, and that installer intentionally never exits on its own, so it cannot close the window it was typed into. Windows then reports whatever exit code the last small program inside the installer happened to return. When that code is negative it arrives unsigned, and 4294901760 is simply the way negative numbers look that way -- it is plain -65536, confirmed by testing against this machine's PowerShell. The installer's own way of saying "I failed" does not reach the exit code at all. In other words, the exit code on this path carries no news either way.
- What BlindPilot did before: any exit code that was not zero was treated as a failed update, and it said nothing else. That contradicted how the Install button already judged the very same installer, where a working `hermes` at the end is what counts.
- What BlindPilot does now: it asks Hermes which version it is before running the installer, and asks again afterwards. If Hermes now reports a newer version, you hear it -- the new version is read out, no matter what the installer process exited with. If Hermes is still on the same version and the installer did not finish cleanly, BlindPilot says the update may not have completed, tells you to read the installer's own output above -- which does explain real failures, in plain words -- and says to try the update again, which is safe to do at any time. If Hermes disappears from the computer, that is still said plainly.
- Who this helps: anyone who ever saw a huge exit code from a Hermes update and could not tell whether Hermes had updated. Real failures still stop BlindPilot from claiming success; finished updates are no longer reported as broken.
