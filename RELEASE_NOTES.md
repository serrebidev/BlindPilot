# BlindPilot 0.29.29

This release finishes Muse Code support. Muse joined BlindPilot a few releases ago able to hold a conversation, but it was a second-class backend: no past conversations, attachments the model could not see, settings that pointed at the wrong file. Every gap found in a full audit against Muse's own protocol is now closed, and each one was measured against the live CLI rather than trusted from documentation.

- Past conversations: Muse was the only backend missing from Recent Conversations, so continuing one meant pasting a session id by hand. All of your Muse conversations now list there -- title, folder, recency -- filter by folder, and reopen with their transcripts. On Windows they are read through WSL, where Muse keeps them, and if Muse ever moves its store, BlindPilot asks a live Muse where it lives instead of guessing.
- Mid-conversation changes that used to be ignored: picking a permission mode after the first turn never reached Muse -- every later turn ran under the old mode. The mode is now applied to the resumed session, and you hear it if Muse refuses. Likewise, reopening a conversation that was parked on a question or an approval now puts that question back in front of you instead of leaving the conversation wedged. Very long conversations, which Muse serves without their history attached, are read back page by page.
- Pictures and skills: an attached image used to arrive as a bare path Muse could not open. Images now travel as pictures the model actually sees -- confirmed live, with the model describing the attached photo. The slash picker lists Muse's own skills for the folder, and typing one runs it the way Muse's own terminal does.
- Status and stopping: the status report now shows Muse's subscription windows -- how much of the current window and the week you have used -- and the version line says the version instead of a workspace warning it printed by mistake. The stop button sends the interrupt Muse reserves for a person pressing stop, measured to end the turn instantly whether the answer has started streaming or not. Tool results clipped at Muse's ~64KB view budget are fetched back whole, up to a megabyte, and a clipped answer is completed from the session log.
- Settings: Backend Settings for Muse pointed at the credentials file, which configures nothing and risks the sign-in if edited. It now points at the real global settings and the folder's project rules.
